# theZoo (collection de malwares, depot `ytisf/theZoo`)
Clone ici : `git clone https://github.com/ytisf/theZoo.git data/datasets/thezoo/repo`
(ton antivirus peut mettre des fichiers en quarantaine : exclus ce dossier ou travaille en machine virtuelle).
Ingestion **sans jamais executer** : `python tools/ingest_thezoo.py` -> caracteristiques + empreintes
(mot de passe des archives : `infected`), puis les fichiers extraits sont supprimes.
